Administrator accounts

Administrators are never created automatically. Use the secure CLI commands below from the project folder.

Run these commands in the same environment (virtualenv) and directory as the app. Passwords are prompted securely and never passed on the command line.
  • flask create-admin — create a new administrator, or promote an existing account by email/username.
  • flask promote-admin you@example.com — promote an existing member to administrator.
  • flask init-db — create missing tables and seed default genres.
  • flask storage-report — print upload storage usage by folder.
  • flask seed-demo --with-admin — generate a real demo catalog with sample videos.

Environment

Configuration lives in .env.

  • SECRET_KEY — session signing key. Use a long random value in production.
  • DATABASE_URL — defaults to SQLite in instance/dodotv.db.
  • UPLOAD_FOLDER — media storage directory. Defaults to uploads/.
  • MAX_UPLOAD_MB — maximum video upload size (default 4096 MB).
  • FFMPEG_BINARY / FFPROBE_BINARY — paths to FFmpeg tools.
  • SESSION_COOKIE_SECURE — set to true when serving over HTTPS.
