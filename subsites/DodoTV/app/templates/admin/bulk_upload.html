How bulk upload works

Everything below happens automatically for each file.

  • Files are validated with FFprobe. Unsupported or corrupt files are skipped with a clear error.
  • Episode titles come from each file name. You can rename them afterwards.
  • Runtime is read from the video and preview frames are generated with FFmpeg.
  • Episode numbers start at the number you choose, skipping numbers already used in the season.
  • Uploading is sequential. Keep this tab open until every file has been processed.

Tips

Get the best results from your uploads.

  • Use Show Name - S01E02 - Episode Title.mp4 style names for readable titles.
  • MP4 with H.264 video and AAC audio plays in every modern browser.
  • Large uploads are limited by MAX_UPLOAD_MB in your .env file.
  • Need to upload to a new season? Create it from the show page first.
