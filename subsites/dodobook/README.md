# DodoBook

DodoBook runs inside [DodoStack](../../README.md). Open [DodoBook](http://dodobook.localhost:8000) to share posts and media, manage friends and groups, and use direct and group chat.

Sign in with your shared account. An administrator approves new DodoBook profiles. Use **Admin → DodoBook** on the main server to approve profiles, edit profile details, and moderate posts. Shared roles and passwords are managed under **Admin → Accounts**.

DodoBook stores social data in `instance/dodobook.db` and files in `static/uploads/` under this directory. The root README explains how to link an existing profile to a shared account.
