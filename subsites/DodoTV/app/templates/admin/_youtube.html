Import from YouTube

Paste a video link instead of uploading a video file. Saving downloads the video into DodoTV. On an existing title, this replaces the video and its subtitles.

For selected languages, enter comma-separated language codes. If both sources have the same language, manually added subtitles take priority. Availability depends on the video.

Keep this tab open while downloading. Long videos can take several minutes.
